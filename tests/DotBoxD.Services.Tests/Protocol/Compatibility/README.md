# Previous-release wire corpus

`PreviousPackageWireFixtureTests` contains exact frames generated by installing
`DotBoxD.Codecs.MessagePack` version `0.1.0-ci.5510` into a separate net10.0 console project.
It transitively uses that release's Services implementation, not a project reference to current code.

The producer calls `MessageFramer.FrameMessage` with `MessagePackRpcSerializer` for:

- Request 42: service `Calc`, method `Add`, instance `instance-7`, payload bytes 1, 2, 3.
- Successful response 42 with payload byte 42.
- Error response 42: message `Denied`, type `PolicyDenied`, empty payload.

Current code must decode each prior frame and write identical bytes, preserving both directions of
interoperation. The cancellation and negotiation preamble goldens are pinned separately. Fixture
updates require an explicit compatibility decision; never regenerate them from the implementation
being tested. A future wire version must keep these fixtures while adding its own corpus and peer
version tests.
